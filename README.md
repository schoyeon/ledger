# 등록금 장부

석박통합 10학기 등록금 납부 · 지도교수 지원금 · 미리 받은 등록금에서 쓴 돈을 한 장부로 맞춰 보는 개인용 앱.

**앱 주소**: https://schoyeon.github.io/ledger/

- 단일 `index.html`. 서버 없음. 입력한 숫자는 **각 기기 브라우저(localStorage)에만** 저장되며 이 저장소에는 올라가지 않는다.
- 다른 기기로 옮기려면 앱 상단 **백업**(JSON) → **복원**.
- 학기 규칙: 1학기 3~8월, 2학기 9~2월. 1-1 = 2026년 1학기.
- 세 숫자: 있어야 할 돈(지원 − 납부) / 실제 보관(− 꺼내 씀 + 채움) / 채워 넣어야 할 돈(꺼내 씀 − 채움).

수정은 `index.html` 을 고쳐 push 하면 1~2분 뒤 반영된다.
